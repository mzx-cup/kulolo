# assets

打包用的静态资源。目前只有应用图标。

## 图标

| 文件 | 说明 |
|---|---|
| `icon-source.jpg` | 源图：库洛米插画（1254×1254），改图标就换这张 |
| `app.ico` | 生成的多尺寸图标，`build_exe.py` 打包时自动带走 |
| `app.png` | 256px 单张，给网页 favicon / README 用 |

改完源图重新生成：

```
python tools/make_icon.py
```

`app.ico` 里有 9 个尺寸（16/20/24/32/40/48/64/128/256），分两档画法：

- **32px 及以上**：完整插画，脸居中、帽尖和蝴蝶结都在画面里；
- **24px 及以下**：只留额头上那枚粉色骷髅徽章——插画细节太碎，
  直接缩到 24px 以下会糊成一团粉色，骷髅反而一眼能认出来。

所有尺寸都是圆角 + 一圈很淡的白边，深色任务栏上不会和背景糊在一起。
